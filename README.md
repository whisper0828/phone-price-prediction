# 手机售价预测 · 二手手机

一个单页（HTML + 原生 JS）的二手手机售价预测演示，基于 300 台真实二手手机样本的 KNN 回归。

四个页面：
1. 封面 —— 项目概览
2. 估一台 —— 输入品牌 / 存储 / 屏幕 / 月数，实时给出估价
3. 批量估价 —— 上传 CSV，一次算完并给出这批货的构成（品牌环图、价格直方图）
4. 依据 —— 300 台样本的散点图，点黄色圆点可看是哪 8 台决定了这个价格

整个模型（300 个训练点 + 标准化参数 + 曼哈顿距离加权 KNN）都内嵌在 `index.html` 里，
不依赖任何外部资源、不联网也能运行。

数据来源：`used_phones.csv`（300 条）。
模型：K = 8，曼哈顿距离，距离倒数加权；留出法验证 MAE 约 169 元，R² ≈ 0.926。
